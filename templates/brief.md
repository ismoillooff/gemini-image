# Image brief

Fill from the user's message; infer what's obvious; ask only for what blocks the
work (one message, assumptions stated).

| Field | Value |
|---|---|
| Purpose / audience | e.g. Instagram promo for a café's morning menu, locals 20–40 |
| Platform → preset / ratio | ig-post 4:5 · ig-story 9:16 · web-hero 16:9 · web-banner 1920×600 · tg-post 16:9 |
| Main subject & focal point | what the eye hits first |
| Composition | framing, angle, empty space for text (where) |
| Style | photo / 3D / flat vector / watercolour … |
| Palette & light | brand colours, mood, time of day |
| Exact text (added locally) | headline, sub-line, price, phone, CTA — verbatim |
| References | logo file, product photo, person photo, previous image |
| Must stay unchanged (edits) | e.g. product shape and label, person's face |
| Must not appear | e.g. other brands, extra text, watermarks |
| Variants | 1 (default) or 2–3 distinct concepts |
| Deliverables | original + sizes/text versions needed |

Assumption line to show the user when you inferred things:
> "Taxminlarim: Instagram post (4:5), fotorealistik, matn keyin qo'shiladi. Boshlayapman."
